# Yaz

Простая нативная Android-клавиатура на Kotlin. Без фреймворков, без интернета,
без аналитики, без свайпа и автокоррекции.

## Что уже есть

- English QWERTY
- Татарская раскладка (русская база + long-press):
  `а → ә`, `о → ө`, `у → ү`, `ж → җ`, `н → ң`, `х → һ`, `е → ё`, `ь → ъ`
- Верхний ряд — 11 клавиш, как в GBoard; `ъ` вызывается long-press на `ь`, `һ` — на `х`
- Цифры 1–0 на верхнем ряду пока отключены (код закомментирован)
- Русские буквы доступны в татарской раскладке; отдельный русский язык убран из переключателя
- Shift / Caps Lock
- Цифры и символы
- Пробел, backspace, enter
- Нижний ряд: `?123`, запятая, глобус, пробел, точка, enter
- Кнопка-глобус: круг, меридиан и линия экватора, без флагов
- Векторные иконки Shift / Enter / Backspace; Shift — контурная стрелка
- Long-press с попапом **в отдельном окне над клавиатурой** и с зазорами между пунктами:
  `а → ә`, `х → һ`, `ь → ъ` и т.д. В попапе нет повтора самой клавиши
- Long-press на символах: `- → — _ – ·`, кавычки, скобки, валюты, математика и т.д.
- `_` показывается без попапа — остальные варианты дублировали бы соседние клавиши
- При long-press клавиатура слегка затемняется (scrim ~20%), попап и нажатая клавиша остаются яркими
- Тапы в зазорах между клавишами срабатывают на ближайшую клавишу
- Учёт системного **navigation bar / gesture inset**: нижний ряд не заходит на полоску
- Тёмная / светлая / авто-тема в стиле Gboard
- Превью клавиши, вибрация, звук
- Настройки: тема, высота клавиш, вибрация, звук + тестовое поле ввода
- **Нет разрешения INTERNET** — в APK вообще нет permissions

## Сборка

Требуется JDK 17, Android SDK 35 и Gradle 8.x.

```bash
cd Yaz
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Установка

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell ime enable com.shagiev.yaz/.KeyboardService
adb shell ime set com.shagiev.yaz/.KeyboardService
```

Проверка:

```bash
adb shell ime list -s
```

Вернуться на Fossify:

```bash
adb shell ime set org.fossify.keyboard/.services.SimpleKeyboardIME
```

  Layouts.kt                  — раскладки EN/TT и символы

  Language.kt                 — языки

## Сверка с GBoard

- Верхний ряд из 11 клавиш; цифры 1–0 пока отключены.
- `ъ` вызывается long-press на `ь`, `һ` — на `х`; в попапе нет дубля самой клавиши.
- Попап `-`: ровно `—`, `_`, `–`, `·`; `_` без попапа.
- Скругление клавиш ~10 dp, крупнее шрифт, контурная стрелка Shift.
- Фиксированная сетка: English и страница `?123` — 93 px, татарский верх/дом — 83 px,
  нижний буквенный ряд татарского — 78 px; высота 50 dp, горизонтальный зазор ~4.8 dp,
  межстрочный ~10.3 dp; Shift/Backspace — 105 px в татарском/скрытом русском и 146 px
  в English; `?123`/Enter и нижний ряд — 146/93 px в обеих версиях; ряды с меньшим числом
  клавиш центрируются с полями.
- Enter перерисован в стиле `keyboard_return`.
- Страница символов: `@ # ₽ _ & - + ( ) /`, ниже пустая служебная клавиша,
  `* " ' : ; ! ?` + backspace. Пустышка — заготовка под будущие спецсимволы.
- Нижний ряд: `?123`, запятая, глобус, пробел, точка, enter.
- Попап вынесен в отдельное окно **над клавиатурой**, как в GBoard; есть боковые отступы и зазор между пунктами.
- При long-press клавиатура приглушается scrim’ом ~20%.
- Осознанно не копировались функции, которых у нас нет: toolbar (GIF/буфер/микрофон),
  эмодзи-клавиша и вторая страница символов `=\<`.

## Ограничения первой версии

- Нет свайпа
- Нет автокоррекции и подсказок
- Нет эмодзи
- Нет голосового ввода
- Нет буфера обмена
- Татарские буквы — через long-press, не отдельными клавишами
