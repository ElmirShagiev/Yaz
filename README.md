# Yaz

**Yaz** (тат. *яз* — «весна»; *яз* — «пиши») — свободная клавиатура для Android
с английской и татарской раскладками. Без интернета, аналитики, рекламы и
лишних разрешений.

Ранняя версия **0.0.2**. Android 8.0+, меньше мегабайта, MIT.

## Идея

У проекта простая мысль: клавиатура должна быть инструментом, а не сервисом.
Она не просит доступ в интернет, не собирает статистику, не подсовывает рекламу
и не пытается угадать за пользователем каждое слово. Только раскладка, клавиши
и предсказуемый ввод.

Название «Yaz» — татарское слово, которое означает и «весна», и «пиши». Отсюда
зелёный баннер, листья и цветы: маленькая весна в мире клавиатур.

За основу взят привычный уклад GBoard — высокие скруглённые клавиши, длинные
нажатия, попап над клавиатурой, — но без облака и лишних функций. Вся отрисовка
и обработка касаний написаны вручную на `Canvas`, без сторонних библиотек.

## Возможности

**Раскладки**

- English QWERTY.
- Татарская раскладка на русской базе: `ә ө ү җ ң һ` вызываются долгим
  нажатием на `а о у ж н х`.
- `ё` и `ъ` тоже доступны через долгое нажатие.
- Переключение языка глобусом; выбранный язык запоминается.
- Shift и Caps Lock.

**Ввод**

- Отдельная страница цифр и символов `?123`.
- Долгое нажатие на символах: тире, кавычки, скобки, валюты, математика
  и другие варианты.
- Превью нажатой клавиши, вибрация и звук — включаются и отключаются.
- Пробел подписан названием текущего языка.
- Клавиши в зазорах срабатывают на ближайшую, а лёгкое движение пальца
  не отменяет нажатие.

**Оформление**

- Светлая, тёмная и автоматическая тема.
- Настройка высоты клавиш от 40 до 70 dp.
- Учёт системной navigation bar и жестового inset: нижний ряд не залезает
  на полоску.
- Скруглённые клавиши, контурные иконки Shift, Enter и Backspace.

**Приватность**

- В манифесте нет разрешения `INTERNET`.
- Нет аккаунтов, аналитики, рекламы и сетевых запросов.
- Настройки хранятся только локально на устройстве.

## Под капотом

- Kotlin, `InputMethodService` и один кастомный `View`, который рисует всю
  клавиатуру на `Canvas`.
- Без AndroidX и сторонних библиотек.
- `minSdk 26`, `targetSdk 35`, JDK 17.
- Раскладки описаны данными в `Layouts.kt`, а не разметкой.
- Тема, высота клавиш, вибрация и звук меняются сразу, без перезапуска
  клавиатуры.

## Установка

1. Скачайте APK на странице
   [Releases](https://github.com/ElmirShagiev/Yaz/releases/latest).
2. Откройте файл и при необходимости разрешите установку из неизвестных
   источников.
3. Включите клавиатуру в настройках Android:
   **Система → Языки и ввод → Виртуальная клавиатура → Управление клавиатурами**
   → **Yaz**.
4. Выберите Yaz как текущую клавиатуру.

Путь к настройкам может немного отличаться в зависимости от прошивки.

<details>
<summary>Для разработчиков: установка через ADB</summary>

```bash
adb install -r Yaz.apk
adb shell ime enable com.shagiev.yaz/.KeyboardService
adb shell ime set com.shagiev.yaz/.KeyboardService
```

</details>

## Сборка

Нужны JDK 17, Android SDK 35 и Gradle 8.13+.

```bash
git clone https://github.com/ElmirShagiev/Yaz.git
cd Yaz
gradle :app:assembleDebug
```

Если Gradle не находит Android SDK, укажите путь в `local.properties`:

```properties
sdk.dir=/path/to/android-sdk
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `KeyboardService.kt` | `InputMethodService`: ввод текста, backspace, Enter, смена языка |
| `KeyboardView.kt` | Отрисовка, касания, превью, попапы, автоповтор backspace |
| `Layouts.kt` | Раскладки English и татарская, страница символов |
| `Key.kt` | Модель клавиши |
| `Language.kt` | Языки и порядок переключения |
| `Theme.kt` | Цвета и режимы темы |
| `SettingsActivity.kt` | Экран настроек и тестовое поле |
| `Prefs.kt` | Ключи `SharedPreferences` |

## Ограничения и планы

Пока нет:

- свайпа по клавиатуре;
- автокоррекции и подсказок;
- эмодзи;
- голосового ввода;
- буфера обмена;
- отдельного ряда татарских букв — они вызываются долгим нажатием;
- русского языка отдельным пунктом — русские буквы есть в татарской раскладке.

Планы:

- отдельная татарская раскладка с клавишами `ә ө ү җ ң һ`;
- эмодзи-панель;
- буфер обмена;
- настраиваемые раскладки;
- свайп как отдельный проект или библиотека.
